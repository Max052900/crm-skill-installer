# 客户沟通版输出档位（客户沟通要点）

对外四档位中的**第二档位**（对外档位总览见 `output-spec.md`）。给客户经理拿去**对客户沟通**用，不进风控审批流程。

与第四档位**资料澄清清单**（`client-checklist-output.md`）的分工：客户沟通版带判断结论，给客户经理**面谈客户**用；资料澄清清单不带判断、纯两张清单，**直接发客户**——两档都保留（用户口径「都留」，见 `rm-voice-corpus.md` 场景 9）。

底座判断（首屏结论卡 + 九步扫描正文五章 + 附录 6 表）照常先跑；本档位是它的**轻量呈现**，把同一套判断重组成客户经理能直接对客户讲的四块。**结论必须与完整预检稿、沟通汇总表一致**：分档档位词、卡点定性、空间结论的语义与数字不得改写（一致性规则见 `comm-summary-table.md`），不得另起判断。

## 何时出这一档

用户说「出客户沟通版 / 客户沟通要点」「给客户经理对客户用的」「跟客户对接的版本」时。默认仍是完整预检稿；本档位要显式触发。

## 固定四块结构（顺序不可变）

1. **判断（前置）** —— 先给结论。两段叙述 + 一句加框结论，措辞用一线词表（这个户 / 能做 / 卡在 XX / 瑕疵怎么调 / 有抓手，见 `narrative-style-guide.md` 第二节）：
   - 第 1 段：经营/征信底子如何 + 真正的卡点是什么、怎么调。
   - 第 2 段：为什么这个卡点最先决定这单能不能推进 + 趋势补充。
   - 结论框：一句话定调——**继承底座四档分档话术**（优质户，优先跟 / 正常户，按流程推 / 有机会，看看 / 放弃）+ 待核查资料（如有），话术唯一出处见 `narrative-style-guide.md` 第五节，不自造二元定调句。
2. **关键信息** —— 全部表格化。按需分块：集团结构 / 经营层面 / 负债与财务 / 个人征信。经营层面一旦引用流水营收，必须列“对公账户营收 / 私人账户营收（个人银行卡 + 微信）/ 合计可识别营收 / 统计期间”，不得只写一个总数。数据进表，不用文字堆数字。
3. **待补资料** —— 表格，每条带优先级标签（最关键 / 重要 / 补充）。来自底座的下一步推进动作 + 材料调整与优化建议 + 待核查资料，合并去重。
4. **需要留意的信息** —— 表格，每条带文字类别标签（开票异常 / 同业收紧 / 客户集中 / 个人多头 / 互保风险…）。来自底座系统层的次级记录（`secondary_tracks`）。

> 完整预检稿的「首屏结论卡四问 / 九步扫描正文五章 / 附录 6 表」结构**不出现**在客户沟通版里；次级记录、逐笔明细该进表的进表，不展开。

## 文案要求

继承报告体硬规则（见 `narrative-style-guide.md` 第七节）：结论前置、句子短、零错别字、零语病、无情绪/营销词、核心数字才加粗。全文用一线词表、禁词表零命中（见 `narrative-style-guide.md` 第二节）。另加客户沟通版专属：

- **数据必须表格化**，不要用文字段落罗列数字。
- **每条信息带文字标签**，不能只靠颜色区分（"标识不够明细"）。

## 排版规格（HTML → A4 PDF）

固定套用模板 [examples/client-comm-template.html](examples/client-comm-template.html)，硬约束：

- **配色克制**：单一深藏蓝（`#1c3a5e`）做强调 + 冷灰阶正文；禁大面积绿/红/黄色块；红/琥珀仅用于极淡底色和小标签（如有转亏、大额其他应收款等风险行可描红；无则不描）。
- **版式**：信纸版心居中（白纸投影），双语眉题（眉题装饰性英文属呈现层例外，不受报告层不夹杂英文规则约束）+ 衬线大标题 + 主体行 + 四格 meta 信息条；章节用衬线标题 + 延伸细线（**不要**中文数字圆徽，已被否）。
- **表格**：表头藏蓝、隔行极淡灰、数字 `tnum` 等宽右对齐、细横线分隔。
- **打印**：`@media print` 转 A4、`break-inside:avoid` 防表格断页。

## 生成流程

1. 跑底座判断，拿到分档 + 待核查资料 / 瑕疵与调整 / 空间提示 / 下一步推进动作 / 系统层次级记录与各附录表数据。
2. 复制 `examples/client-comm-template.html` 为 `<客户名>-客户沟通要点.html`，把四块内容填进对应区块。
3. 校对收口（金额/主体名/证件号与底座一致、无错别字、无语病）。
4. 用 gstack browse 转 PDF（沙箱需 `dangerouslyDisableSandbox`）：
   ```
   B=~/.claude/skills/gstack/browse/dist/browse
   $B goto "file://<html 绝对路径>"
   $B pdf "<pdf 绝对路径>" --format a4 --print-background
   ```
5. `open` 给用户确认。

## 反面教训（已踩过的坑）

- **不要用 html-anything 重新生成**同类文档——同项目已有人工改良的同款样式 HTML（预检稿或本模板）时直接当底板改，重生成会丢失积累的样式（"重复造轮子"）。
- html-anything 的 `exec-briefing-memo` 模板被否（太设计化、不像正式报告）。
- design-html 等 web 设计 skill 对静态打印报告是过度工程（Pretext 动态布局 / 本地服务器 / PNG 对比板都用不上），只取设计原则手做即可。

## 样板

`examples/client-comm-template.html` 是本档位公开定稿模板，内容只保留占位符，不包含真实客户名称或数据。
