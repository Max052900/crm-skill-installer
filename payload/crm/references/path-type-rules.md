# Path Type Rules

> **定位说明（2026-07）**：本文件自 2026-07 起为**系统层内部判断规则**，不再作为报告主线；判断逻辑并入 `rm-scan-chain.md` 第 1-5 步（"经营证据可抬路径"等判断语义保留，供系统层字段与回归等价判定用）。报告层的结论语言见 `narrative-style-guide.md` 第五节（四档 + 待核查资料）。下文提及"首屏判断卡第 1 问"等旧报告落位的表述，仅作历史对照；新首屏结论卡格式见 `first-screen-card.md`。

本文件定义 **Path Type（这是什么路）** 的判断规则（旧首屏判断卡第 1 问；现为系统层内部字段）。

目标：在判断"什么压住这条路"之前，先判断"这是一条什么路"。核心是——**主体不算天然标准强案时，也要先判断经营证据是否足以抬路径，而不是先验压低。**

## 一、为什么先判路径类型

最容易退回成预审系统的地方，不是后面怎么问，而是一开始就把"主体一般 / 负债存在"当成先验压制项，忽视经营证据对路径的提升作用。

因此系统层判断的入口是：**先识别这是什么路，再决定是否进入更谨慎判断。**（运行时报告主线是九步扫描链，见 `rm-scan-chain.md`。）

## 二、判断顺序（3-1 路径类型识别节点）

1. 看主体是否天然占优（主体清楚、关系干净、个人征信无硬伤、规模标准）。
2. 不论主体是否占优，**都要先扫描经营证据**：
   - 实际经营年限
   - 稳定流水 / 明确对公交易对手 / 真实回款痕迹
   - 高新、科创等资质（仅作粗路由提示）
   - 营收 / 开票 / 税票支撑
   - 经营场地、员工、设备等经营实体特征
3. 判断这些经营证据是否**足以把案件抬到可继续看路径**。
4. 只有在"主体不占优 且 经营证据也不足以抬路径"时，才走更谨慎路线。

**禁止**：主体一般 → 直接归入弱主体案 → 默认谨慎 / 压低。这是必须拦住的跑偏。

## 三、路径类型枚举

路径类型固定为以下五类，不增减、不换名：

| 路径类型 | 含义 | 样板 |
| --- | --- | --- |
| 标准强主体路径 | 主体天然占优，经营与承载基本清楚 | —— |
| 经营证据可抬路径 | 主体不算天然强案，但经营证据 / 资质 / 交易痕迹足以抬路径 | 样本 B |
| 经营可见度待验证路径 | 主体清楚、行业规模有继续看基础，但经营证据待补 | 样本 A |
| 谨慎路径 | 主体不占优 且 经营证据不足以抬路径 | —— |
| 路径未明 | 主体 / 经营 / 借款承接不清，需先 clarify 才能定路 | （见 `clarify-rules.md`） |

## 四、与其他规则的关系

- Path Type 回答"这是什么路"；`priority-rules.md` 回答"什么压住这条路"。两者均为系统层内部概念。
- 先定 Path Type，再在该路径下选唯一核心矛盾（`primary_contradiction`，系统层字段）。
- Path Type 不得触发银行、产品、额度、期限分支。
- **报告层落位**：Path Type 不再作为报告章节或标题出现；对应的判断结果通过四档分档（首屏第 1 问"这个户能不能做"）与"瑕疵与调整"（第 2 问）表达，话术与映射见 `narrative-style-guide.md` 第五节。
