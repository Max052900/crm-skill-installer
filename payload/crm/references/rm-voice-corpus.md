# 一线客户经理表达校准语料（公开合成版）

本文件只保留可复用的表达规则。所有示例均为合成语句，不对应真实客户。

## 场景 1：先给档位

- 先说“优质户 / 正常户 / 有机会 / 放弃”，再说理由。
- 缺材料也先按已有信息给初判，缺口列入待核查资料。

## 场景 2：第三档不把话说死

- 使用“有机会，看看”。
- 适用于方向依赖一项关键证据、材料补出来后才能定的客户。

## 场景 3：正常户与有机会的分界

- 现有材料已经够推，落正常户。
- 是否能推取决于待补关键证据，落有机会。
- 水母与增值税申报表信息源一致时，可以择一使用，不重复索取。

## 场景 4：瑕疵后必须有调整方向

- 不只写“哪里有问题”。
- 固定写成“当前瑕疵 → 怎么调整 → 补什么材料 → 哪个指标会变化”。

## 场景 5：私人账户经营回款

- 个人银行卡和微信里的可识别经营回款可以计入企业实际营收。
- 必须分列对公营收、私人账营收和合计可识别营收，并完成内部划转去重。

## 场景 6：要材料直接列清单

- 对客户直发的资料清单不加销售铺垫。
- 每项写清材料名称、统计期间和需要说明的问题。

## 场景 7：销售话术不进入分析报告

- 不生成报价预期、利率承诺、成交推动或进度承诺。
- 报告只交付事实、分析、瑕疵、调整方向和材料动作。

## 场景 8：给银行客户经理的信息

- 先写主体与主营，再写营收和负债，最后写材料缺口。
- 不替银行做审批结论，不承诺产品、额度和期限。

## 场景 9：资料澄清清单

- 固定两张表：需要补的资料、需要说清楚的问题。
- 不出现内部档位和判断过程；数值、期间、来源与其他输出保持一致。
